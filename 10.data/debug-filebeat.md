---
description: Debugging a running filebeat
---

 - To debug a running filebeat look for the MCP server filebeat.
 - Check all the resources it offers and the tools.
 - For anything related to configuration, check the resource to get the current configuration.
 - INVESTIGATIONS SHOULD BE READ-ONLY: DO NOT EDIT FILES
 - DO NOT CREATE OR EDIT CONFIGURATION FILES
 - DO NOT LOOK FOR CONFIGURATION IN THE CURRENT DIRECTORY OR WORKSPACE. USE THE MPC SERVER RESOURCES INSTEAD
